# Генератор ключей «Физпрактикума»

`Генератор ключей.html` — открыть в Edge или Chrome (интернет не нужен).

1. **Один раз:** «Создать новый секретный ключ». Скачается `fizpraktikum-secret.key` — хранить надёжно, никому не передавать, в репозиторий не класть.
   Открытый ключ (64 знака) со страницы задать в GitHub: Settings → Secrets and variables → Actions → Variables → `FZ_LICENSE_PUBKEY`. Без него выпуск не собирается.
2. **Выдача ключей:** «Открыть файл секретного ключа», вставить коды компьютеров (по одному в строке, после кода можно написать, кому выдан), выбрать «бессрочно» или «до даты», «Выдать ключи».
3. **Активация:** ключ вводится в окне «Активация» программы, или файл `license.fzl` кладётся рядом с `Fizpraktikum.exe` либо в общую папку класса.

Ключ — подпись Ed25519 строки `FZ1|код компьютера|срок`. Программа проверяет её открытым ключом (src-tauri/src/license.rs), поэтому ключ подходит только к своему компьютеру и подделать его без секретного ключа нельзя.


## Генератор ключей.exe

Та же программа без браузера: обычное окно Windows (7, 8, 10, 11; 32 бита, без установки, без интернета).
Ключи совпадают с генератором в HTML (проверено подписью на одном секретном ключе). Журнал выдачи —
«Журнал ключей.csv» рядом с программой (если папка закрыта для записи — в «Документах»).
Исходники — `win/`, сборка на Linux — `win/build.sh` (mingw-w64).
