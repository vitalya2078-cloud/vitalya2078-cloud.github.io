# PHYSICS — Лабораторная работа № 3 для Windows

Отдельное настольное приложение, которое запускает существующую лабораторную работу № 3 из проекта `fizika2`.

## Принципиальное условие

Исходный модуль `fizika2/src/labwork3.js` не переписывается и не редактируется. Приложение использует штатную сборку PHYSICS и открывает маршрут `#lw-3` сразу после запуска.

Сохраняются исходные этапы лабораторной, модель установки, эксперименты, расчёты, контрольные вопросы, сохранение прогресса и печать отчёта.

## Сборки

GitHub Actions создаёт два Windows x64-файла:

- установщик NSIS `.exe` — установка в Windows, ярлыки в меню «Пуск» и на рабочем столе;
- portable `.exe` — запуск без установки.

Файлы публикуются как артефакты workflow **Build PHYSICS Lab 3 for Windows**.

## Локальная разработка

Требуются Node.js 22+, Python 3.12+ и Windows.

1. Из корня репозитория выполнить `python fizika2/src/build.py`.
2. Скопировать собранные `fizika2/index.html`, `content.json`, `pics/`, `audio/`, `fonts/` и `manifest.webmanifest` в `desktop/lab3/app/`.
3. Создать `desktop/lab3/icon.ico` из `fizika2/icon-192.png`.
4. В `desktop/lab3` выполнить `npm install`, затем `npm run dist`.

Данные лабораторной хранятся локально в профиле приложения. Для выполнения работы подключение к интернету не требуется.
