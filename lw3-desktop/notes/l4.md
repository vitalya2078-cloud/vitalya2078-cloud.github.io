# Определение ёмкостей конденсаторов

## Цель работы

Ознакомиться с методами измерения электрической ёмкости конденсатора; экспериментально проверить законы параллельного и последовательного соединения конденсаторов.

## Оборудование

Генератор напряжений (регулируемый источник «0…+15 В»), два мультиметра, миниблоки «Интегратор тока», «Ключ», «Конденсатор» эталонной ёмкости, «Конденсатор» неизвестной ёмкости. Переключатель 2 миниблока «Ключ»: «А» - зарядка от источника, «В» - разрядка через интегратор. Демпфирующий ключ 5 («Сброс») обнуляет интегратор. Мультиметр 9 показывает напряжение зарядки $U$, мультиметр 8 - выход интегратора $U_{инт}$.

## Теория

### Конденсатор и ёмкость

> **Определение.** **Конденсатор** - устройство для накопления электрического заряда: две обкладки, разделённые диэлектриком. Поле сосредоточено между обкладками, заряды обкладок равны по величине и противоположны по знаку.

> **Определение.** **Электроёмкость конденсатора** - отношение заряда обкладки к напряжению между обкладками: $C = q/U$. Единица - **фарад** (Ф).

1 Ф - ёмкость конденсатора, напряжение на котором меняется на 1 В при сообщении ему заряда 1 Кл. Ёмкость зависит от формы и размеров обкладок, зазора между ними и диэлектрика, но не зависит от $q$ и $U$.

Ёмкость плоского конденсатора и уединённого шара:

$$C = \frac{\varepsilon\varepsilon_0 S}{d}, \qquad C_{шара} = 4\pi\varepsilon\varepsilon_0 R$$

Если убрать диэлектрик, ёмкость уменьшится в $\varepsilon$ раз.

### Соединения конденсаторов

**Параллельное соединение**: напряжение на всех конденсаторах одинаково, а заряды складываются, $q = q_1 + q_2$:

$$C_{пар} = C_1 + C_2 + \ldots$$

Ёмкость батареи больше наибольшей из ёмкостей.

**Последовательное соединение**: заряд всех конденсаторов одинаков, а напряжения складываются, $U = U_1 + U_2$:

$$\frac{1}{C_{посл}} = \frac{1}{C_1} + \frac{1}{C_2} + \ldots, \qquad C_{посл} = \frac{C_1 C_2}{C_1 + C_2}$$

Ёмкость батареи меньше наименьшей из ёмкостей.

**Энергия** заряженного конденсатора $W = CU^2/2$.

## Метод измерения

Заряд конденсатора пропускают через интегратор тока; напряжение на его выходе пропорционально прошедшему заряду:

$$q = CU, \qquad q = \gamma U_{инт} \quad\Rightarrow\quad C = \frac{\gamma U_{инт}}{U}$$

$\gamma$ - **градуировочная постоянная** интегратора. __Её находят по эталонному конденсатору известной ёмкости__ $C_э$:

$$\gamma = \frac{C_э U_э}{U_{инт\,э}}$$

## Порядок выполнения

1. Собрать схему для эталонного конденсатора. Записать значение $C_э$ с миниблока.
2. Включить питание и установить напряжение зарядки 3–4 В по мультиметру 9. Все измерения проводят при одном и том же $U$ - менять его нельзя.
3. Измерение: ключ 5 - «Сброс», переключатель 2 - «А» (зарядка); затем разомкнуть ключ 5 и перевести переключатель в «В» - заряд проходит через интегратор. Записать $U_{инт}$.
4. Сделать по три измерения для $C_э$, $C_x$, параллельного и последовательного соединений.
5. Измерить $C_x$ мультиметром в режиме измерения ёмкости для сравнения.

## Обработка результатов

По средним значениям $U_{инт}$ находят $\gamma$, затем ёмкости $C_x$, $C_{пар}$, $C_{посл}$. Сравнивают измеренные ёмкости соединений с вычисленными по формулам:

$$C_{пар}^{теор} = C_э + C_x, \qquad C_{посл}^{теор} = \frac{C_э C_x}{C_э + C_x}, \qquad \delta = \frac{|C - C^{теор}|}{C^{теор}}\cdot 100\ \%$$

## Техника безопасности

Работу начинают с разрешения преподавателя. Собирать и разбирать схему - только при выключенном питании («Сеть»). Не касаться оголённых контактов; не превышать напряжение 3–4 В. При неисправности выключить питание и сообщить преподавателю. По окончании работы выключить кнопками «Сеть» блок генераторов и блок мультиметров.
