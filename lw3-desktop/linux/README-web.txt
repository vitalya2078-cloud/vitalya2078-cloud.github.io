Показатель адиабаты — версия для браузера
=========================================

Подходит для любой Astra Linux (в том числе 1.7), других Linux и компьютеров,
где нельзя устанавливать программы.

Как запустить
1. Распакуйте архив в любую папку (например, в «Документы»).
2. Откройте файл index.html в браузере: Firefox, Chromium или Яндекс Браузер
   (двойной щелчок или «Открыть с помощью…»).
3. Сделайте закладку — в следующий раз откройте программу из закладок.

Важно
- Интернет не нужен.
- Работа сохраняется в браузере на этом компьютере. Не очищайте данные сайтов
  браузера, пока работа не сдана, и сохраните файл работы (Ctrl + S) для преподавателя.
- Отчёт в PDF: шаг «Отчёт» → «Печать» → принтер «Сохранить в PDF».
- Папка класса (автосдача работ) есть только в установленной программе;
  здесь работа сдаётся файлом.

Установленная программа для Astra Linux 1.8 и новее: файл pokazatel-adiabaty_amd64.deb
(установка: sudo apt install ./pokazatel-adiabaty_amd64.deb).
