# ЛР № 3 · Показатель адиабаты — программа для Windows

Отдельное приложение для учебных компьютеров: лабораторная работа № 3 «Определение показателя
адиабаты» (метод Клемана — Дезорма). Работа та же, что в «Практикуме» на сайте `fizika2`,
интерфейс сделан заново под большой экран, мышь и клавиатуру.

## Что внутри

- **Сама работа — общий код с сайтом.** Модель установки, вопросы допуска и защиты, расчёты, проверки,
  действия на установке и отчёт лежат в `fizika2/src/lw3-core.js`. Сайт (`labwork3.js`) и программа
  рисуют только свои экраны. Правка в ядре попадает в оба места.
- **Оболочка программы** — `src/`: `shell.html` (разметка и стили), `desktop.js` (экраны, профили студентов,
  клавиши, график давления, звук, файл результата), `teacher.js` (режим преподавателя), `sha256.js` (подпись файла).
- **Окно Windows** — `src-tauri/` (Tauri 2, WebView2). Две команды: «Сохранить как» и полный экран.
- `build.py` собирает `dist/index.html`: помощники и значки берутся из исходников сайта, без копий.

## Возможности

- Профили студентов на одном компьютере; работа сохраняется автоматически после каждого действия.
- Шаги: допуск → подготовка → 3 опыта → обработка → выводы и защита → отчёт (4 листа А4, печать или PDF).
- Установка во весь рост, живой график h(t) и температура газа, название процесса в баллоне, чек-лист опыта.
- Клавиши: `Пробел` (держать) — компрессор, `Enter` — главное действие, `K`, `O` — краны K и K₀, `P` — питание,
  `Ctrl+S` — файл результата, `Ctrl+P` — печать, `F11` — полный экран, `F1` — подсказка.
- **Файл результата `.lw3`**: полное состояние работы с подписью HMAC-SHA-256. Им сдают работу преподавателю
  и продолжают её на другом компьютере. Файл, исправленный вручную, программа помечает как изменённый.
- **Режим преподавателя**: перетащить файлы группы → сводная таблица (этап, h₁/h₂, ⟨γ⟩ ± ⟨Δγ⟩, ε, попытки,
  подлинность), разброс ⟨γ⟩ по группе, отчёт любого студента с печатью, выгрузка в Excel (CSV).

Ограничение подписи: ключ хранится в программе. Подпись защищает от правки в Блокноте, но не от программиста.

## Сборка

Готовые файлы собирает GitHub Actions (`.github/workflows/lw3-desktop.yml`): сначала тесты, затем сборка на Windows.
В артефакте `LR3-Adiabata-windows`:

- `LR3-Adiabata-setup.exe` — установщик NSIS. Ставится **без прав администратора** (в профиль пользователя).
- `LR3-Adiabata-portable.exe` — запускается без установки, например с флешки.

Тег `lw3-v1.0.0` дополнительно публикует релиз с этими файлами.

Локально (нужны Python 3, Node 22, Rust):

```bash
python3 lw3-desktop/build.py          # интерфейс → lw3-desktop/dist
cd lw3-desktop && npm ci && npx tauri build
```

Требования на компьютере: Windows 10 или 11 и WebView2 Runtime (обычно уже установлен). Установщик при
необходимости ставит WebView2 сам; для этого нужен интернет. Программа не подписана сертификатом, поэтому при
первом запуске Windows SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».
