# CORE — Preview 0.6.3

Мобильный sci-fi clicker / idle-core prototype.

## Что изменилось
- Стабильное непрерывное вращение трёх атомных орбит ядра: transform задаётся напрямую через requestAnimationFrame.
- Новый мягкий фоновой ambient: длинные низкие пады, без резких ударов и навязчивого ритма.
- **Автодобыча больше не включена на старте.** В начале: уровень 1, баланс 100, ручной тап +3, производство 0/сек.
- Автодобыча стала отдельным покупаемым модулем.
- Раздел «Прокачка» переработан: базовое усиление ядра + модульные карточки 2×2.
- Добавлены рабочие модули: Автодобыча, Импульсный усилитель, Комбо-матрица, Контур хранения.
- Все покупки модулей сохраняются в localStorage.
- Нижняя навигация и существующие настройки сохранены.

## Запуск
```bash
python3 -m http.server 8080
```
Откройте `http://localhost:8080/`.

- 0.6.3: заметная пульсация самой главной кнопки + отдельный tap-импульс через Web Animations API.
- 0.6.3: ambient переведён на бесшовный Web Audio loop без слышимого перезапуска.
- 0.6.3: все 4 модуля имеют 5 уровней; автодобыча стартует с 0,35/сек и растёт постепенно.
- 0.6.3: старые сохранения 0.6.2 мигрируются: купленный модуль становится уровнем 1.
