# Физика по учебнику — пилот (fizika2)

Новое приложение, сделанное с нуля по структуре учебника Т. И. Трофимовой «Курс физики»
(7 частей, 33 главы, § 1–275). Конспекты, сценарии роликов, рисунки и вопросы — собственные,
текст и рисунки учебника не копируются.

- Сайт: `https://vitalya2078-cloud.github.io/fizika2/`, зеркало без VPN: `https://fizika.gitverse.site/v2/`
- Открыта глава 1 «Элементы кинематики» (§ 1–4): 4 урока, финальное испытание.

## Устройство
- `book.js` — структура учебника и контент глав (уроки: ролик, карточки, симуляция, вопросы).
- `scenes.js` — палитра, сцены роликов (холст), рисунки карточек (SVG), обложки глав, аватары, симуляции.
- `app.js` — опыт, уровни, комбо, значки, экраны, видеоплеер, карточки, проверки, тренировка.
- `icons.js` — значки Lucide (ISC). `shell.html` — разметка и стили.
- `tts_el.py <voice_id>` — озвучка роликов ElevenLabs с разметкой времени → `../audio/`, `voice.json`.
- `build.py` — сборка `../index.html`; база вопросов экзамена и рисунки берутся из `../../fizika`.

Публикация: ветка `main` (GitHub Pages) и `python3 fizika/src/publish.py <клон GitVerse>` (кладёт пилот в `v2/`).
