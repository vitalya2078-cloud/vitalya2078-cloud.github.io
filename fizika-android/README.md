# Физика — Android-приложение

Нативная оболочка (Java, WebView) запускает новый курс по учебнику из `../fizika2`.
Перед сборкой выполни `python3 ../fizika2/src/build.py`. В APK встраиваются интерфейс,
база вопросов, рисунки и доступные аудиофайлы; приложение работает офлайн.

## Онлайн-обновления

APK проверяет отдельные зеркала курса:
- GitVerse: `https://fizika.gitverse.site/v2/`
- GitHub Pages: `https://vitalya2078-cloud.github.io/fizika2/`

Нативная оболочка проксирует запросы через `/mirror/gv2/` и `/mirror/gh2/`, поэтому
не требуется CORS. Новая версия интерфейса скачивается в локальное хранилище и
безопасно применяется при следующем запуске. Если новая версия не отметит успешный
старт за 7 секунд, APK вернётся к встроенной версии. База вопросов обновляется отдельно.
Прогресс курса хранится в `localStorage` под ключом `f2` и не удаляется при OTA-обновлении.

## Сборка

Нужны JDK 17+ и Android SDK (platform 35, build-tools 35).

```bash
python3 ../fizika2/src/build.py
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

## Подпись

Ключ подписи хранится вне репозитория в `keystore.properties`. Для установки поверх
уже установленной версии обязательно используй тот же release-keystore, которым
подписан текущий APK. Без него Gradle соберёт debug-подпись — такую сборку нельзя
установить поверх релизной версии без удаления старого приложения.
